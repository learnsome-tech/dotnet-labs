## Goal

You can generate and expose an OpenAPI document with AddOpenApi and MapOpenApi.

In the lesson: A client requests the mapped document endpoint and receives JSON whose open API field identifies the document version. This is a web transcript because the host remains running. The exact document contains every route and schema, so the panel shows only stable representative lines. In a build pipeline, fetch the document and compare it with the previous version when a compatibility review matters.
