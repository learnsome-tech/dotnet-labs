## Goal

You can read and write modern C#: records, pattern matching, switch expressions and the everyday syntax the rest of the course relies on.

In the lesson: Two more things you meet before any code of your own. A using directive marked global applies to every file in the project, so the list at the top of a file shrinks to whatever is special about that file, and most projects keep the global ones together in one small file. A project also switches on implicit usings, which asks the S D K to add the obvious set for the project type: system, system dot linq, and for a web project the hosting namespaces too. And the entry point can be a bare run of statements; the compiler still generates a class with a main method underneath, so there is only less to type.
