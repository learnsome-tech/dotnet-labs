## Goal

You can layer configuration by environment and keep local secrets out of source control.

In the lesson: The user secrets commands initialise a store for the project, save one development value, and list the resulting key. These lines are an accurate transcript, but they cannot execute here because the dot net SDK is absent. Never paste a real credential into a lesson, a terminal recording, or a commit. The value shown is deliberately fake. In a shared repository, commit the project identifier and the setup instructions, while every developer creates their own local values.
